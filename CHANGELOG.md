# Changelog — Misty Garden

## 2026-11-11 — скрапинг через прокси

**Проблема.** Статьи с сайтов под геоблокировкой (пример — `developers.openai.com`) не скачивались:
напрямую сайт отвечает 403, через прокси — 200.

**Причина** (две, найдены по очереди):
1. `trafilatura.fetch_url` берёт прокси из `http_proxy` только при установленном PySocks и
   трактует его как SOCKS. PySocks в окружении нет → скрапер с самого начала ходил напрямую.
2. `kb_core.py` при импорте удалял `HTTP_PROXY` и подобные из окружения всего процесса — побочный
   эффект на всех, кто его импортирует (в т.ч. на скрапер).

**Что сделано:**
- `scrape_articles.py` — загрузка страниц через `httpx` (понимает обычный HTTP-прокси из окружения,
  ходит по редиректам, браузерный User-Agent); trafilatura используется только для извлечения текста.
- `kb_core.py` — переменные прокси больше не удаляются; `QdrantClient(..., trust_env=False)` —
  обход прокси только для локального Qdrant (kb-api и так через `trust_env=False`).
- Проверено: с выставленным `HTTP_PROXY` Qdrant и kb-api отвечают; OpenAI-статья скачалась
  (16.6K символов), Хабр без регрессии; `update_kb.ps1` → +22 чанка (5513), `smoke_test.py` 8/8.

**Следствие:** скрапинг теперь целиком зависит от прокси `127.0.0.1:12334` — если он выключен,
падают все загрузки (см. README).

**Осталось:**
- `docs.vllm.ai/.../installation` — скачано всего 384 символа (страница рисуется скриптами в браузере),
  для полноценного текста нужен headless-рендер.
- Мёртвые ссылки в `catalog/ai-llm.md`: `habr.com/ru/articles/969502` (удалена), две на
  `digital-razor.ru` (404, вторая обрезана на `-`) — поправить адреса или убрать.
